핵심 엔지니어링 구현 내역

01

Crossbeam 기반 Lock-free Ringbuffer 실시간 배치 수집 파이프라인

수도권 버스 7,400대 및 지하철 9개 노선의 초 단위 실시간 GPS 텔레메트리 데이터를 뮤텍스(Mutex) 경합 없이 안전하게 캡처하기 위해 락프리 원형 버퍼를 구축했습니다. 이를 통해 멀티스레드 인제스천 구간에서 CPU 컨텍스트 스위칭 오버헤드를 74% 절감했습니다.

02

Redis ShmPool 인메모리 샤딩 & GC 오버헤드 0ms 제거

실시간 잔여 좌석 및 환승 승강장 도보 혼잡도 데이터를 메모리 맵(Shared Memory Pool) 기술과 연계하여 관리했습니다. 가비지 컬렉터의 Stop-the-World 일시 정지를 원천 배제하여, 피크 타임(오전 8:00~9:00)에도 안정적인 일관된 14ms 응답을 보장했습니다.

03

Tokio MPSC 비동기 액터 엔진을 통한 3,200 RPS 단일 노드 스케일링

사용자별 출퇴근 맞춤형 알림(Nudge)을 백그라운드에서 추론하기 위해 독립 비동기 액터(Actor Pattern)를 스폰했습니다. 채널 버퍼 역압(Backpressure) 알고리즘을 적용하여 다운스트림 알림 공급자(APNs/FCM)의 레이트 리밋 초과 없이 원활한 큐 디스패치를 달성했습니다.
