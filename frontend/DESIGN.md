# Portfolio

The home page is a personal work index. Lead with Jaemin's name and existing profile photograph. Give projects, tools and experience a consistent reading order; use the owner's own descriptions and actual uploaded media.

- Use the existing blue for links, dark ink for titles and pale neutral rules for grouping. Keep media at its original aspect ratio when opening it. Avoid decorative counters, status dots and artificial browser chrome.
- Use the site's Korean sans family. The name is the largest text. Section titles share one size, metadata uses a smaller regular weight, and Latin technical terms can wrap independently.
- Wide screens pair a narrow stack index with a broad project list. Narrow screens follow the same DOM order in one column. Section navigation follows that order.
- Reveal sections once using opacity and a short vertical offset. Content is visible before JavaScript enhances it. Keyboard focus and reduced-motion settings take precedence.
- Brittany Chiang's [experience and project lists](https://brittanychiang.com/) inform the relationship between dates, thumbnails and descriptions. Lee Robinson's [personal site](https://leerob.com/) informs the short first-person introduction.
